# AGENT.md - Telegram Bot Testing MCP Server Guide

This guide documents the architecture, setup, development workflow, and conventions for the `telegram-bot-mcp` project.

---

## 1. Project Overview

`telegram-bot-mcp` is a Model Context Protocol (MCP) server designed to enable AI coding agents to interact with, test, and verify Telegram bots. It uses Telegram's MTProto protocol (via GramJS) to perform end-to-end user actions such as sending commands, reading formatted responses, and clicking inline keyboard buttons.

It supports both Telegram's **Test Environment** (DC 2 with automated test phone numbers and fixed OTPs) and the **Production Network**.

## 2. Directory Structure

```
/root/bot-mcp
├── dist/                  # Compiled JavaScript files
├── src/
│   ├── index.ts           # MCP server entrypoint and stdio transport initialization
│   ├── config.ts          # Environment variables parsing and configuration validation
│   ├── telegram.ts        # GramJS MTProto client wrapper and interaction methods
│   ├── tools.ts           # MCP tool definitions and handlers
│   └── auth-helper.ts     # CLI helper for generating Telegram StringSession
├── .env.example           # Environment template
├── package.json           # Package definition and scripts
├── tsconfig.json          # TypeScript configuration
└── AGENT.md               # AI agent reference documentation
```

## 3. Development Commands

The project uses `pnpm` as the package manager:

- **Build**: `pnpm build` (compiles TypeScript to `dist/`)
- **Development Run**: `pnpm dev` (runs `src/index.ts` with `tsx`)
- **Production Run**: `pnpm start` (runs `dist/index.js`)
- **Generate Session**: `pnpm login` (interactive/automated tool to log into test/prod server and save `TELEGRAM_SESSION` to `.env`)

## 4. MCP Tools Reference

The server exposes the following tools to MCP clients:

1. `telegram_send_command`
   - **Arguments**: `bot_username`, `command`, `wait_response` (default: `true`), `timeout_seconds` (default: `10`)
   - **Usage**: Sends a `/command` to the bot and returns the sent message and bot's response with any inline keyboard buttons.

2. `telegram_send_message`
   - **Arguments**: `bot_username`, `text`, `reply_to_msg_id?`, `wait_response` (default: `true`), `timeout_seconds` (default: `10`)
   - **Usage**: Sends arbitrary text messages or payloads to the bot.

3. `telegram_click_inline_button`
   - **Arguments**: `bot_username`, `message_id`, `button_text?`, `button_index?`, `wait_update` (default: `true`)
   - **Usage**: Triggers callback queries on inline keyboard buttons attached to a bot message.

4. `telegram_send_and_verify`
   - **Arguments**: `bot_username`, `input_text`, `expected_contains`, `timeout_seconds` (default: `10`)
   - **Usage**: Convenience assertion tool for end-to-end verification.

5. `telegram_get_chat_history`
   - **Arguments**: `bot_username`, `limit` (default: `10`)
   - **Usage**: Retrieves recent messages and message metadata.

6. `telegram_clear_chat`
   - **Arguments**: `bot_username`
   - **Usage**: Deletes dialog history for clean testing states.

## 5. Configuration & Authentication

Set in `.env`:
- `TELEGRAM_API_ID`: App API ID from `https://my.telegram.org`
- `TELEGRAM_API_HASH`: App API Hash from `https://my.telegram.org`
- `TELEGRAM_SESSION`: StringSession generated by `pnpm login`
- `TELEGRAM_TEST_MODE`: `true` to use Telegram Test Server (DC 2) or `false` for Production
- `DEFAULT_TARGET_BOT`: (Optional) Default `@bot_username`

### Test Server Quick Login
When `TELEGRAM_TEST_MODE=true`:
- Phone numbers: `999662XXXX` (e.g. `9996621111`)
- OTP Code: `22222`
- Run `pnpm login` to generate and persist the session automatically.

## 6. Client MCP Configuration Example

To register this server in an MCP host (such as Antigravity, Claude Desktop, or custom agent runner):

```json
{
  "mcpServers": {
    "telegram-bot": {
      "command": "node",
      "args": ["/root/bot-mcp/dist/index.js"],
      "env": {
        "TELEGRAM_API_ID": "12345678",
        "TELEGRAM_API_HASH": "your_api_hash",
        "TELEGRAM_SESSION": "your_session_string",
        "TELEGRAM_TEST_MODE": "true"
      }
    }
  }
}
```
